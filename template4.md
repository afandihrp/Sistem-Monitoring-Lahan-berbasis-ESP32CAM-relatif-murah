1.  **Diskripsi Umum Implementasi**

CD-4 adalah dokumen capstone yang menjelaskan proses implementasi atas
rancangan solusi yang telah disusun secara detil di CD-3. Secara umum,
bagian implementasi menjelaskan wujud akhir atau prototype solusi
berikut dengan prosedur pengoperasian solusi tersebut. Dalam hal ini,
CD-4 terdiri dari tiga bagian: (1) diskripsi umum implementasi, (2)
detil implementasi, dan (2) prosedur pengoperasian solusi.

Diskripsi umum implementasi menjelaskan prosedur atau tata cara yang
digunakan untuk mewujudkan rancangan solusi ke dalam wujud riil. Dalam
hal ini, wujud akhir solusi perlu dipertegas bilamana berupa: hardware,
software, model, framework, proses, gabungan antara komponen tersebut,
dan lain sebagainya. Selain itu, bagian ini juga menjelaskan segala alat
dan bahan yang digunakan dalam proses implementasi.

Aturan tata tulis dalam penulisan dokumen *capstone* adalah sebagai
berikut.

- Batang tubuh dokumen ditulis menggunakan *font* *Times New Roman*
  berukuran 12.

- Ukuran spasi 1,5.

- Judul sub-bab ditulis tebal.

- Tata letak diatur *justified*, kecuali pada gambar dan tabel yang
  diletakkan di tengah.

- Setiap tabel dan gambar harus memiliki judul.

- Judul gambar ditulis di bawah gambar. Judul tabel ditulis di atas
  tabel. Judul tabel dan gambar tidak ditulis tebal.

- Penulisan sitasi dan referensi menggunakan format IEEE.

2.  **Detil Implementasi**

Bagian ini menjelaskan proses dan luaran terkait implementasi secara
detil. Paparan detil implementasi sangat bergantung pada jenis solusi
yang diusulkan, bilamana solusi berupa hardware, software, model,
framework, proses, dan lain sebagainya.

Luaran utama solusi berbentuk software adalah source code. Dengan
demikian, paparan harus berisi seluruh source code yang benar-benar
dibuat oleh tim capstone. Jika source code tersebut diambil/diperoleh
dari source code yang sudah ada, maka paparan hanya berisi source code
utama yang sangat berkaitan dengan modul sistem dan dikerjakan oleh tim
capstone. Dengan demikian, dokumen CD-4 tidak perlu berisi seluruh
source code yang digunakan di dalam software solusi. Dalam paparan
tersebut, source code dijelaskan dalam bentuk per blok di mana panjang
tiap blok diupayakan tidak melebihi satu halaman. Source code ditulis
menggunakan font Courier New berukuran 10. Dalam dokumen CD-4, mahasiswa
tidak hanya memaparkan source code, tetapi juga menjelaskan kegunaan
instruksi, variable, dan fungsi yang ada di dalam source code. Dalam hal
penyusun menggunakan source code yang sudah ada, penyusun wajib
mendeklarasikan penggunaan source code tersebut dan mencantumkan sumber
source code di daftar pustaka. Jika software tersebut menghasilkan
tampilan, baik dalam format web, desktop, maupun mobile, maka paparan
juga berisi screenshot seluruh tampilan software berikut dengan
penjelasannya. Jika software juga melibatkan penggunaan database, maka
paparan juga berisi screenshot tampilan database, baik struktur tabel,
relasi, dataspace, dan lain sebagainya.

Luaran utama solusi berbentuk hardware adalah tampilan hardware.
Tampilan hardware berupa tampilan luar maupun tampilan komponen-komponen
di dalamnya. Tampilan juga dapat berupa foto PCB yang dibuat. Selain
foto tampilan, mahasiswa juga wajib menjelaskan prototype hardware
tersebut dengan detil, baik untuk tiap-tiap modul maupun keseluruhan
sistem. Paparan juga berisi implementasi hardware tersebut di lingkungan
(jika ada).

Luaran utama model adalah simulasi. Dengan demikian, fokus utama adalah
implementasi model ke dalam suatu simulasi. Implementasi dalam bentuk
simulasi dapat dilakukan jika implementasi dalam bentuk fisik dianggap
sulit untuk dilakukan, baik karena biaya yang besar, keterlibatan
perangkat dalam jumlah yang banyak, atau lahan/ruang yang sangat luas.
Dalam hal ini, paparan berisi scenario simulasi dan hasil simulasi.
Hasil simulasi pada umumnya berupa angka yang digunakan untuk
pengukuran. Hasil simulasi juga dapat dilengkapi dengan visualisasi
simulasi, khususnya untuk model-model perencanaan jaringan, rute, dan
lain-lain. Seluruh source code yang ditulis di software simulasi harus
dipaparkan dan dijelaskan secara detil baik variabel, fungsi, dan
instruksinya.

Secara umum, luaran juga dapat ditunjukkan menggunakan video rekaman.
Video rekaman menjadi penting untuk menjelaskan perilaku sistem atau
solusi. Video diunggah ke cloud dan link video ditulis di dalam paparan.
Link video dapat lebih dari satu.

3.  **Prosedur Pengoperasian**

Bagian ini berisi seluruh prosedur pengoperasian solusi. Dengan kata
lain, bagian ini memaparkan panduan penggunaan. Panduan ini penting
ditulis agar solusi dapat diduplikasikan dan dioperasikan dengan baik
tidak hanya oleh tim penyusun. Dengan demikian, panduan pengoperasian
perlu ditulis dengan detil. Panduan pengoperasian dapat dilengkapi
dengan gambar dengan ukuran yang memadai atau video panduan penggunaan.
Dalam hal penyusun menambahkan video, video dapat diunggah ke cloud dan
link video dibagikan di dalam dokumen CD-4.
